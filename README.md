# Portfolio Music Player 🎵

A simple, yet versatile **Java-based music player** built as part of my portfolio.  
It supports loading local audio files, basic playback controls, playlists, and a minimal graphical interface.

---

## Features

- Load and play audio files (e.g. MP3, WAV – whatever your implementation supports)  
- Basic controls: play, pause, stop, next, previous, seek  
- Playlist support: save, load, add, remove tracks  
- GUI interface (JavaFX / Swing / etc.) *or* command-line mode  
- Volume control, seeking, track metadata display (title, artist, duration)  
- Optional: shuffle, repeat, and queue management
